# FlowOpt AI 🚦

### AI-Based Traffic Congestion Prediction and Adaptive Traffic Signal Optimization

## About the Project

FlowOpt AI is a machine-learning-based traffic optimization application designed to predict traffic congestion and recommend optimized traffic signal timings.

The project combines machine learning, traffic analysis, and an interactive four-way traffic simulation to demonstrate how intelligent signal timing can help manage traffic flow.

## Key Features

- Traffic congestion and delay prediction.
- Machine learning-based analysis using Linear Regression.
- Adaptive green signal time recommendation.
- Traffic signal optimization.
- Interactive four-way intersection simulation.
- Traffic dataset visualization.
- Downloadable traffic dataset.

## Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Scikit-learn
- Plotly

## How to Run Locally

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Dataset

The application uses synthetically generated traffic data for model training and demonstration. It does not currently represent live road sensor measurements.

## Project Status

Developed as an academic project to demonstrate machine learning applications in intelligent traffic management.
